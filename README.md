# 📊 Dashboard de Vendas - Power BI

Este projeto é um dashboard interativo de análise de vendas desenvolvido no Power BI, utilizando uma base de dados estruturada com foco na visualização de indicadores estratégicos. O objetivo principal é transformar dados brutos em insights acionáveis para suporte à tomada de decisões.

---

## 💡 Objetivo

Criar uma análise visual das vendas por meio de:

- Conexão e modelagem de dados no Power BI  
- Tratamento e limpeza com Power Query  
- Criação de dashboards com visuais interativos  

---

## 🛠️ Tecnologias Utilizadas

- **Microsoft Power BI** (Modelagem, Power Query, Visualizações)
- **Base de dados estruturada** (formato não especificado)
- **DAX** para criação de medidas e cálculos

---

## 📈 Visualizações Criadas

- Receita Total x Custo Total por Região 🌍  
- Evolução de Vendas por Mês 📆  
- Vendas por Categoria de Produto 📦  
- Distribuição de Vendas por Perfil de Cliente 🧑‍🤝‍🧑  
- Indicadores de Desempenho (KPIs)

As análises consideram:

- Localização da venda  
- Tipo de produto  
- Perfil do comprador  
- Período da transação  

---

## 🧠 Aprendizados

- Conexão e transformação de dados no Power BI  
- Criação de medidas e KPIs com DAX  
- Design de dashboards com foco em usabilidade e clareza  
- Aplicação de boas práticas em visualização de dados
